Qwen3-TTS 与 IndexTTS 2.5 单目录部署

发表于2026-10-20|更新于2026-10-20|AI

TTS（Text-to-Speech，文本转语音）可以把解说稿直接生成音频。在 Windows 11 和 RTX 3060 12GB 上，Qwen3-TTS 1.7B 与 IndexTTS 2.5 都已完成中文短句生成验证。日常使用可以从三个启动文件进入网页，生成的音频自动保存到固定目录。

源码、Python、模型、缓存、参考录音和输出统一放在 D:\AI\TTS，两套应用分别使用独立的 Python 依赖环境。部署环境与实测数据记录于 2026 年 10 月 20 日。

模型选择与实测环境

安装包含三个用途不同的模型：

模型 用途 本地模型目录
Qwen3-TTS-12Hz-1.7B-CustomVoice 选择预设音色，配合文字指令控制表达 models\qwen-customvoice
Qwen3-TTS-12Hz-1.7B-Base 根据参考录音克隆声音 models\qwen-base
IndexTTS 2.5 根据参考录音配音，并使用情绪控制功能 models\indextts-2.5

Qwen 的 CustomVoice 和 Base 对应不同任务，需要分别下载权重。模型用途可对照 Qwen3-TTS 官方说明和 IndexTTS 2.5 模型说明。

项目 实测配置
系统 Windows 11 Pro
显卡 NVIDIA GeForce RTX 3060，12GB 显存
CPU / 内存 Intel Core i9-12900K / 64GB
显卡驱动 610.88
Qwen Python 3.12.15
IndexTTS Python 3.11.13
PyTorch / torchaudio 2.8.0，CUDA 12.8 构建，即 cu128
Transformers Qwen 4.57.3；IndexTTS 4.52.1
Gradio 两套环境均为 5.45.0

这里的 Python 独立环境，是指每个应用都有自己的 .venv 文件夹，单独保存所需的软件包。两个项目使用的 Transformers 版本不同，分别管理可以避免安装一方依赖时影响另一方。

本次使用 BF16 半精度运行，即用较少的位数保存计算中的数值，以降低显存占用。没有安装 FlashAttention、DeepSpeed，也没有启用自定义 CUDA 内核编译。

统一目录结构

统一管理需要同时控制安装目录和缓存目录。只把源码放在 D 盘，Python 下载工具和网页组件仍可能使用用户目录或系统临时目录。

启动脚本为当前进程设置环境变量，不修改系统 PATH。NVIDIA 驱动由 Windows 管理；浏览器下载文件的保存位置由浏览器设置决定。

运行管理脚本

下载 Windows 运行管理脚本，2026-10-20 版，ZIP，5,112 字节。

附件包含本次部署使用的三个 .cmd 启动文件，以及 env.ps1、start.ps1、run-model.py、layout.ps1。解压后将启动文件放在 D:\AI\TTS 根目录，四个脚本放在其 scripts 子目录。

附件负责环境变量、模型启动、输出保存和目录关联。Python、第三方工具、模型权重及依赖需要按下文安装。

环境配置的主要内容

env.ps1 从脚本所在位置计算安装根目录，并设置以下路径：

环境变量 作用与保存位置
UV_PYTHON_INSTALL_DIR uv 管理的 Python，放在 python
UV_CACHE_DIR uv 下载与安装缓存，放在 cache\uv
HF_HOME、HF_HUB_CACHE、HF_XET_CACHE Hugging Face 缓存，放在 cache\huggingface 下
MODELSCOPE_CACHE ModelScope 缓存，放在 cache\modelscope
TORCH_HOME、TORCH_EXTENSIONS_DIR PyTorch 缓存，放在 cache 下
GRADIO_TEMP_DIR 网页临时音频，放在 temp\gradio
TEMP、TMP 当前进程临时目录，放在 temp
CUDA_CACHE_PATH CUDA 计算缓存，放在 cache\cuda

此外，脚本配置了 pip、Numba、Matplotlib 等组件的缓存目录，并通过 PYTHONNOUSERSITE=1 避免加载用户级 Python 软件包。uv 的 Python 注册和全局路径修改也已关闭。uv 相关变量可查阅其环境变量文档。

保存 Qwen 音频与音色文件

run-model.py 在调用 Qwen 官方网页前，为生成函数增加自动保存：预设配音写入 outputs\qwen-customvoice，克隆配音写入 outputs\qwen-base。文件名包含时间和随机标识，减少重名覆盖。

网页保存的 Qwen 音色文件放在 voices，而不是长期依赖临时目录。它们是后续克隆时加载的 .pt 文件，不是可直接播放的音频。

Gradio 返回统一目录中的文件时，需要通过 allowed_paths 允许访问 voices 和 outputs。缺少该设置会出现 InvalidPathError，导致已保存的文件无法通过网页返回。

使用与维护

长讲稿按句子或分镜分段生成，单独检查多音字、数字、英文缩写和停顿。先生成短句确认音色与表达，再扩大文本长度，更便于发现问题和重新生成。

日常重点保留 voices、outputs、模型和运行配置。临时压缩包可在安装完成后清理，依赖下载缓存可保留以便修复环境。发生报错时，先查看 logs 中最近的模型日志；显存不足时可通过 nvidia-smi 检查当前占用。

备份整个目录便于保存模型与数据，但移动目录或换电脑后，Python 虚拟环境和 Windows 目录链接需要重新建立。源码升级前也应记录现有提交与软件包版本，并重新检查缓存路径修改、网页参数和输出保存行为。
