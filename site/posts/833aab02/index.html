ScnTerm: 终端常用路径的快速切换

发表于2026-11-11|更新于2026-11-11|软件

我用 SSH 连接服务器时，经常需要进入几个固定目录：项目源码、编译输出、配置文件或日志所在的位置。路径一长，每次重新连接后都要输入一遍 cd，或者翻找之前的命令历史。

我在自己维护的 ScnTerm 中加入了常用目录菜单。进入一个目录后，可以直接把当前位置保存下来；下次按 Alt+P 打开列表，用方向键选择，再按回车进入。每个 SSH 连接保存自己的路径，打开菜单时只显示当前连接的记录。

ScnTerm 是我基于 WezTerm 维护的个人终端版本，整体介绍见终端改版与使用指南。这次的路径菜单用于 ScnTerm 内置 SSH 连接，快捷键由 Lua 配置提供。

用 Alt+P 保存与切换路径

使用我的个人配置时，先按 Alt+L 打开启动菜单，选择已配置的 SSH 服务器。连接后，在远端 Shell 的空白命令提示符下操作。

第一次使用，需要先进入准备收藏的目录。以下路径仅作示例，请替换为服务器上实际存在的目录：

按 Alt+P，选择“添加当前目录”，再按回车。ScnTerm 会读取当前 SSH Shell 的目录，把它保存到本机的记录文件中。相同路径重复添加时，不会产生重复条目。

之后切换到其他位置，或重新连接同一台服务器，再按 Alt+P 就能看到已保存的路径。选中目标目录并按回车，当前 SSH 窗格就会执行目录切换，菜单随之关闭。

按键或选项 操作
Alt+P 打开当前 SSH 连接的常用目录菜单
↑、↓ 上下选择条目
“添加当前目录”后按 Enter 读取并保存当前目录
选中路径后按 Enter 在当前 SSH 窗格进入该目录
- 删除选中的路径记录
Esc 关闭菜单

选中的条目使用亮橘黄色文字、加粗和箭头标记。路径较多时，列表会随选择滚动。减号只删除收藏记录，服务器上的目录和文件不受影响。

每个 SSH 连接保存自己的目录

不同服务器上的目录用途和位置并不相同。我希望连接到哪台服务器，就看到哪台服务器的常用路径，因此列表按 SSH 连接分别保存。

同一个连接的新标签页和分屏窗格共用路径列表。切换目录只作用于当前操作的窗格，其他窗格仍留在各自的工作目录。

区分列表时，会同时使用连接名称、服务器地址、端口和用户名。因此，同一台服务器使用不同账号连接时，可以分别维护目录；修改连接名称或目标信息后，也会对应另一份列表。

这里保存的是完整路径。目录后来被移动、删除，或当前账号失去访问权限时，切换命令会由远端 Shell 返回相应错误。可以用 - 移除旧记录，再进入新位置重新添加。

快捷键与 SSH 配置分开维护

我把个人配置拆成了几个独立文件，主 wezterm.lua 保留完整目录，并在对应章节注明设置位置：

文件 与路径菜单有关的设置
wezterm.lua 加载配置模块，保留目录及说明
ssh.lua SSH 开关、服务器地址、端口、用户名和目录记录文件位置
keys.lua Alt+L、Alt+P 等快捷键及命令面板中的按键标注
serial.lua 串口连接、日志与高亮配置

使用这套配置时，四个 Lua 文件放在同一目录。服务器信息在 ssh.lua 中填写，ssh_enabled 设为 true 后，连接入口会出现在启动菜单中。仓库保留示例地址和用户名，使用前需要替换。

keys.lua 已包含 Alt+P，无需再次添加。文件保存后自动重载；调整快捷键时，也要同步修改该文件中命令面板的按键标注。

ShowDirectoryMenu 是 ScnTerm 增加的动作，需要使用包含该功能的程序版本。我的个人配置对旧版 ScnTerm 和原版 WezTerm 做了兼容检查：不支持这个动作时，会跳过绑定。因此，Alt+P 没反应时，需要同时检查程序版本、实际加载的配置，以及是否进入了内置 SSH 会话。只更新 Lua 文件不会给旧程序增加目录菜单。

使用时的几个边界

路径菜单使用 ScnTerm 能够识别的内置 SSH 连接。本地 PowerShell、串口窗格，以及在本地 Shell 中手动执行系统 ssh 命令建立的连接，不使用这套菜单。日常从配置中的 Alt+L 入口连接服务器即可。

添加当前目录时，ScnTerm 会向当前远端 Shell 发送一条读取 $PWD 的命令。$PWD 表示这个 Shell 当前所在的目录，返回内容经编码后传回终端；因此记录的是当前窗格的实际工作位置。远端需要兼容 POSIX 的 Shell，例如 Bash 或 Zsh，以及 printf、base64、tr，无需安装 ScnTerm。

查询命令会显示在当前会话中，是否写入命令历史由远端 Shell 的设置决定。切换目录则向同一个 Shell 发送 cd 命令，路径会处理引号，支持空格、中文等内容。

添加和切换目录前，先回到空白命令提示符。 如果当前还有未提交的半行命令，或正在运行编辑器、交互程序，应先处理完再使用菜单，避免把目录操作发送给前台程序。
