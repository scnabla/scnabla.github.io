用 ScnTerm 的 Lua 配置编辑器管理串口、SSH 和快捷键

发表于2026-11-19|更新于2026-11-19|软件

我把 ScnTerm 的串口、SSH 和快捷键配置拆成了三个 Lua 文件。拆开以后，找文件容易了，但把开发板从 COM3 换到 COM5，还是得打开 serial.lua 找到那条连接。另一个常见操作是给快捷键换个键位，真正需要改的只有一个键名，旁边却可能是一段我想原样保留的 Lua 动作。

为这些日常修改，我做了一个独立的 Windows 配置编辑器。选中连接或快捷键，改好以后，窗口会列出即将写入文件的几行。编辑器和终端各自运行，平时仍然可以用文本编辑器维护同一套 Lua。终端的安装和整体配置见 ScnTerm 使用指南。

打开自己的配置目录

从配置程序发布页下载 Windows x64 压缩包 ScnTermConfig-windows-x64.zip，完整解压后双击 ScnTermConfig.exe，无需另装 Python 或 Rust。

程序会先查找 %USERPROFILE%\.config\wezterm。配置放在其他位置时，点“打开配置目录”，选择主配置 wezterm.lua 所在的文件夹。第一次想试一下，可以像下图一样先打开解压目录里的 examples。窗口顶部显示正在编辑的目录，保存示例只会改到那份示例。

页签 对应文件 可修改的内容
串口连接、日志、高亮规则 serial.lua 端口和通信参数、日志目录、时间戳、关键词颜色
SSH ssh.lua 服务器列表、地址、用户名和连接方式
快捷键 keys.lua 按键、修饰键和动作
其他配置 · 只读 wezterm.lua 等文件 查看原文

如果所有设置都写在一份 wezterm.lua 里，当前版本只能查看这份主文件。可编辑的页签读取同目录下对应的独立文件，缺少哪个就提示哪个。拆分和加载模块的写法可以参考随程序提供的配置示例。

改一次串口，看看 Lua 会写入什么

以上图的“开发板控制台”为例。假设 Windows 现在把设备识别成了 COM5，板端波特率仍为 115200。在左侧选中这条连接，只改右侧的“端口”，然后点“预览并保存”。这次差异中应当只有端口那一行，减号表示原内容，加号表示准备写入的内容。

点“确认保存”后，再回到 ScnTerm，按 Alt+L 选择这条连接。端口和波特率在下次连接时生效。对于已有连接，Lua 省略波特率时，窗口显示终端实际使用的 9600。只改端口，编辑器就保留波特率原来的省略写法。

“连接时记录日志”按连接设置。在“日志”页可以统一修改保存目录、单个文件大小和接收时间戳，这些设置用于下一次开始记录。想在连续输出中看清故障信息，可以在“高亮规则”中新增一组，选好文字颜色，再填写匹配内容：

  • 固定文字用“关键词”。例如把 [故障] 单独写在一行，方括号也会参与匹配。
  • 相似的词用“正则表达式”。例如 \bfail(?:ed|ure)?\b 可以匹配完整的 fail、failed 和 failure。将这条规则的“区分大小写”设为“否”，大写的 FAILED 也能匹配。

两个框的灰色“格式参考”都是输入示例。填写自己的内容后提示就会消失。高亮随终端配置重载生效，保存到磁盘的日志仍是原来的文字。串口连接和日志的使用细节见 ScnTerm 串口调试。

添加 SSH 服务器和修改快捷键

在“SSH”页点“新增服务器”，给连接取一个能在启动菜单里认出的名称，比如“编译机”。把服务器地址填成自己的 主机名:端口，再填用户名。普通 SSH 连接的“会话类型”选 None。使用随程序提供的示例时，还要把“启用 SSH 菜单”设为“是”。预览并保存 ssh.lua 后，可以从 ScnTerm 的 Alt+L 菜单选择服务器。登录之后想直接进入项目目录，可以使用终端常用路径的快速切换。

在“快捷键”页，已有绑定可以只换按键。例如想把示例中“按数字交换窗格”的入口从 F5 改成 F6，选中 F5 那一条，将“按键”改为 F6，保留修饰键 NONE 和原来的自定义动作。保存后，原来负责数字选窗格的 Lua 代码会继续使用。

也可以点“新增绑定”，填写按键和修饰键，从“动作”中选一个操作，例如“新建标签页”。组合键里的修饰键写成 CTRL|SHIFT，单独按一个键则填 NONE。如果同时改了 SSH 服务器和快捷键，要在两个页签分别预览、确认。保存 keys.lua 时，SSH 页尚未保存的输入仍留在窗口里。

手写配置的保留与恢复

我希望这个工具能和手写 Lua 配合使用。比如把波特率写成 baud = get_baud()，具体数值由函数决定。编辑器读取文件时只解析代码结构，这种字段会保留原表达式并显示为只读。对于能识别的普通字段，它只替换相应位置，周围的注释、条件分支和无关设置都可以保留。

每次确认保存前，程序都会在配置目录的 .scnterm-config-backups/ 下备份原文件。如果预览期间又用文本编辑器改了同一文件，保存会被拦下，此时应重新读取并核对修改。想撤回刚才的改动，可以回到对应页签点“恢复备份”，选择那次保存记录，预览后确认。连续改过几次时，从最近一次开始逐次恢复。
