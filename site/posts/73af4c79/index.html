光影题笺照片水印工具使用指南

发表于2026-10-15|更新于2026-10-15|软件

光影题笺是一款 Windows 本地照片水印工具，可以为照片添加文字、拍摄信息、品牌 Logo 和版权署名。当前采用底栏水印：将内容放在照片下方，配合底部参数条、四周留白或模糊背景，调整位置、字号和颜色后，另存为 JPEG 或 PNG。

名字与本站的「光影拾笺」专栏相呼应。软件原名“照片边框”，目前提供 0.1.0 Windows x64 试用版。照片在本机处理，无需上传；当前一次处理一张照片。

下载光影题笺 Windows x64 试用版

三种水印样式

三种风格共用文字与导出设置，可以根据照片选择。

风格 适合的排版 可以调整的内容
底部参数条 保留照片主体，在下方集中放置拍摄信息 底栏高度、文字、Logo
四周留白 在照片周围留出空间 上、左、右边距，底栏高度，圆角与阴影
模糊背景 用照片本身的颜色和形状延展背景 背景边距、模糊强度、底栏高度、圆角与阴影

上、左、右边距各自设置，底边由底栏高度控制，不另叠一层留白。边距和底栏高度都按原照片短边的比例计算。纯色边框提供浅底深字、深底白字两种配色；模糊背景保留照片颜色，模糊强度为 0 时不做模糊。

添加边框不会为了腾出文字空间而缩小原照片。不开启圆角时，照片构图完整保留；开启圆角会遮去四角，阴影则需要边距留出足够空间。

文字和 Logo 集中设置

点击紫色的“文字/Logo设置”按钮，可以编辑标题、相机、镜头、拍摄参数、时间和署名。相机信息从照片中读取，缺失或不合适的内容可以手动修改，也可以留空隐藏。除此之外，还能添加最多 8 条自定义文字。

字号支持自动适应或统一指定，文字颜色可以跟随边框配色，也可以自行选择。品牌 Logo 目前提供小米和索尼，可以调整大小及位置。

右侧的方格定位区用于安排底栏内的文字和 Logo：

  • 拖动图层时吸附方格，方格密度可以调整。
  • 蓝线对应原照片左右边缘，金色虚线对应照片中心。
  • “左对齐”“居中”“右对齐”均以原照片为基准。
  • 方向键移动 1 像素，按住 Shift 后每次移动 10 像素。

文字和 Logo 的调整范围是原照片宽度内的底栏，不进入照片主体，也不占用左右边框。网格与参考线只在编辑时显示，不写入成品。

点击“确定”应用修改，点击“取消”放弃本次调整。文字、Logo 或阴影确实放不下时，软件会提示调整；不合适的参数不会替换上一份可用预览。

给照片添加一行版权署名

“文字/Logo设置”中有独立的“版权署名”勾选框，默认不勾选。开启后可填写一行姓名、年份和网站，例如：

软件内置的占位示例是 © 2026 xxx · xxx.com，使用时换成自己的内容。没有网站可以只保留年份与姓名。署名的字号、颜色和位置都可以调整，内容过长时需要缩短或减小字号。

旁边的“恢复默认”只恢复占位示例，不改变勾选状态和其他文字设置。软件界面底部的作者信息不会自动加到照片上。

一次排好，保存为个人样式

常用的边框、底栏高度、字号、文字颜色、位置、Logo 和署名可以保存为个人样式。样式支持应用、更新、复制和重命名，适合多张照片使用相同排版。

切换照片后会重新读取该照片的拍摄信息，不会把上一张照片的相机参数作为个人样式套用。

顶部“设置 → 个性化”还可以给中央工作区选择背景图片并调整明暗。这里改变的是软件工作区，不会改变导出照片的背景；照片的边框效果仍在右侧“水印设置”中选择。

下载与运行

下载光影题笺 0.1.0 Windows x64 试用版（ZIP，29.11 MiB）

本次更新包：2026-10-15 修订版，包含新名称、新界面，以及镜头名称中竖线字符引发文字排版失败的修复。

  1. 完整解压下载包，到有写入权限的文件夹。
  2. 运行 photo-watermark-desktop.exe，点击“选择照片”或按 Ctrl+O。
  3. 选择边框风格，在“文字/Logo设置”中编辑内容与排版。
  4. 预览完成后，选择 JPEG 或 PNG，点击金色的“导出照片”按钮，或按 Ctrl+S 保存。

导出生成新文件，同名文件自动编号，不覆盖原片。JPEG 可以调整质量，但重新编码会产生有损压缩。边距、底栏和照片效果等滑条在松开后更新预览；预览与导出使用同一份布局。

请保留完整程序目录，不要只复制 EXE：tools 中的 ExifTool 用于读取照片拍摄信息，licenses 保存第三方许可，README.txt 和 COPYRIGHT.txt 分别提供使用说明及软件许可。

个人样式和界面设置保存在程序旁的 data 目录。更新程序时保留自己的 data；把程序交给其他人前，不要附带个人数据目录。

试用范围

当前版本支持单张 JPEG、PNG，尚不支持批量处理、RAW、16 位 PNG 和 APNG 动画。透明 PNG 会与白底合成。

运行需要系统已安装 Microsoft Edge WebView2 Runtime，下载包未内置该运行时。

照片在本地处理。主动填写的姓名、网站、拍摄时间等文字会成为导出图片的一部分，分享前请检查成品中的画面与文字。
