ScnTerm: WezTerm UART 串口调试支持与使用

发表于2026-11-08|更新于2026-11-11|软件

我把日常串口调试需要的参数配置、菜单连接、命令收发、文本日志和关键词高亮加入了 ScnTerm。这篇是 ScnTerm 终端改版与使用指南的串口子文章，集中介绍 UART 连接与配置；项目整体、下载安装和自动更新安排见主文章。

串口直接使用 ScnTerm 的标签页和窗格。Lua 配置保存常用连接，按 Alt+L 选择设备，在同一个窗口中查看开发板输出、输入命令，也可以切换到本地终端或 SSH 标签页。

从 WezTerm 串口功能到 ScnTerm 的完善

WezTerm 已经提供串口连接基础，包括 serial_ports 配置、wezterm serial 命令和终端显示。ScnTerm 沿用这些实现，通过 serial2 库调用系统串口接口；我在此基础上补充了通信参数、连接行为、日志保存和关键词高亮。

功能 当前 ScnTerm 的支持
保存连接 通过 Lua 保存多个串口连接，分别设置名称和端口；个人配置集中放在 serial.lua
通信参数 波特率、数据位、校验位、停止位和流控
打开连接 从启动菜单选择已配置的串口，也可使用命令行
查看与输入 在终端窗格中接收设备输出，输入命令并发送给设备
关闭与重连 关闭串口窗格释放端口，再从连接入口手动打开
文本日志 自动或手动记录、接收时间戳、按大小分文件、状态提示
关键词高亮 每种颜色可对应多个关键词和正则表达式，只给匹配文字着色

串口和 SSH 共用菜单、标签页及窗格操作，各自仍使用对应的连接实现。串口窗格直接收发设备数据，即使主配置把 PowerShell 设置为默认 Shell，打开串口时也会直接连接设备。

下面以 Windows 的 COM3 和 1500000 波特率为例，端口名称与通信参数需要按实际设备修改。

在 Lua 中配置串口

使用拆分后的个人配置

我的个人配置已经把串口、SSH 和快捷键分开维护：

文件 配置内容
wezterm.lua 主入口、通用外观和默认 Shell，保留设置目录并加载其他文件
serial.lua 串口连接、文本日志和关键词高亮
ssh.lua SSH 连接与常用目录记录位置
keys.lua Alt+L 等快捷键

四个 Lua 文件放在同一目录，程序仍加载主 wezterm.lua。修改串口时，在 serial.lua 的 M.apply(config) 中调整对应配置；修改快捷键时编辑 keys.lua。主配置通过 require 加载模块，保存模块文件后也会自动重载。

连接参数用于新连接；日志公共设置用于下一次开始记录；高亮规则重载后会更新当前画面和滚动历史。拆分文件不会改变日志默认保存位置，它仍跟随主 Lua 所在目录。

安装 ScnTerm 后不会自动启用这套个人配置。使用仓库完整配置时，还需按其说明准备字体和图片资源，并替换示例设备参数。已有自己的配置时，也可以继续把串口设置写在主 Lua 中。

参数对应关系

配置项 含义与可选值
name 菜单中显示的连接名称，需要与其他连接名称区分
port 系统串口名称，例如 Windows 的 COM3、Linux 的 /dev/ttyUSB0
baud 波特率，需要与设备一致，并由串口驱动支持
data_bits 数据位，可选 5、6、7、8
parity 校验位：'None' 无校验、'Odd' 奇校验、'Even' 偶校验
stop_bits 停止位，可选 1、2
flow_control 流控：'None' 无流控、'Software' 软件流控 XON/XOFF、'Hardware' 硬件流控 RTS/CTS
log_on_connect 是否在本次连接建立时自动开始记录日志，默认 false

示例中的 8N1 对应 8 个数据位、无校验、1 个停止位，流控另设为 None。旧 Lua 配置省略通信参数时，仍保留原有的 9600、8N1、软件流控默认值，因此建议把设备要求的参数明确写出。

Windows 的端口名称可在设备管理器中查看。多个设备可以在 config.serial_ports 中分别增加条目，每项使用独立名称和实际端口。

连接设备与输入命令

使用 Alt+L 打开串口

  1. 连接设备，确认 Windows 中的串口名称，与 Lua 中的 port 一致。
  2. 启动 ScnTerm，确认主配置加载成功。
  3. 按 Alt+L 打开启动菜单，选择 board-console。
  4. ScnTerm 在当前窗口新建串口标签页，接收设备输出。

空闲、断开与重新连接

串口一段时间没有输出是正常状态。ScnTerm 在没有可读数据或读取超时时继续等待，不把设备安静当作连接断开。

情况 当前处理方式
设备暂时没有输出 保持连接，继续等待数据
端口不存在或无法打开 显示打开失败信息，检查端口名称和占用情况后重新连接
读写出现不可恢复错误 结束连接，保留异常窗格和已有输出
主动关闭串口窗格 结束后台收发并释放端口
修改通信参数 重载配置后，关闭原连接，再打开串口

USB 转串口仍连接电脑，但开发板断电或下游串口线断开时，电脑端的串口可能仍可打开。当前没有通用方法仅凭“没有输出”确认开发板是否在线，也没有主动向设备发送心跳命令。

需要重新连接时，关闭原串口窗格，再按 Alt+L 选择对应连接。设备拔出后重新插入，还要核对系统分配的端口名称。当前采用手动重连，端口被其他软件占用时，需要先释放占用。

串口日志保存

自动记录与手动开关

串口输出可以保存为便于阅读的 UTF-8 文本。日志只记录从设备接收的内容；输入的命令如果被设备回显，也会随输出保存，本机发送但设备没有回显的内容不单独写入日志。

在前面的串口条目中，将 log_on_connect 改为 true，该连接建立时就会自动开始记录。保持 false 时，可以进入串口窗格后按 Alt+L，选择开始记录；正在记录时，菜单提供停止操作。

操作只影响打开菜单时的串口窗格，各个串口可以分别启停。本地终端和 SSH 窗格不显示串口日志操作。也可以在现有快捷键配置中给以下动作绑定自选按键；使用拆分配置时放在 keys.lua：

  • wezterm.action.StartSerialLogging：开始记录。
  • wezterm.action.StopSerialLogging：停止记录。

顶部标签栏右侧显示“串口日志：记录中”“串口日志：未记录”或失败状态，使用亮橘黄色文字和深紫色圆弧底色。提示与窗口右侧保留间距，并与原有 Lua 状态文字一起显示。切换回本地终端或 SSH 后，串口状态自动隐藏。

进度条与控制字符

日志保存会去除颜色、窗口标题等终端控制指令，保留可读文本。中文字符或控制指令分成多次到达时，会连续处理，避免直接按每次读取结果切断内容。

文件写入在后台进行。文件创建或写入失败、待写数据超过限制时，停止日志并显示失败提示，串口继续收发；排除原因后可以手动重新开始，创建新的日志文件。

串口关键词与正则表达式高亮

设备输出较多时，我希望直接看到错误、警告和超时信息。ScnTerm 可以按规则改变关键词本身的颜色，同一种颜色对应多个词，也可以用正则表达式匹配一组相近写法。

在 serial.lua 的 M.apply(config) 中设置 config.serial_highlighting；使用单文件配置时，放在主 Lua 的 return config 前。已有这项配置时修改原表即可：

第一组使用玫红色，匹配中文错误词以及 error、fail、failed、failure、fatal；第二组使用亮橘黄色，匹配警告与超时。颜色可以替换为自己的十六进制颜色值。

设置 用法
foreground 这一组使用的文字颜色
keywords 按原样匹配的普通关键词，[故障] 中的方括号也按普通字符处理
patterns 正则表达式列表，用分组、可选部分和重复规则覆盖多种写法
case_sensitive 放在 serial_highlighting 中设置公共值，或放在某组中单独设置；默认 false，不区分大小写

keywords 和 patterns 可以同时使用，也可以只保留其中一项。普通关键词按子串匹配；示例正则中的 \b 限定英文单词边界，避免把较长单词中的一小段误当成独立关键词。Lua 的 [[...]] 写法可以保留正则里的反斜杠，省去再次转义。

正则采用 Rust regex 语法，支持分组、选择、重复、字符类和 Unicode，不支持回溯引用和前后查找。整个匹配范围都会变色；同一段文字命中多组时，靠前的规则优先，后续规则仍可给剩余部分着色。

所有串口共用这一组规则，不需要逐个设备配置。保存后会更新当前内容和滚动历史，不用断开设备；清空 rules 或删除 serial_highlighting 就恢复设备原色，没有额外的菜单开关。表达式或颜色填写错误时会提示配置位置，配置重载失败后沿用上一次有效设置。

匹配支持中文、分批接收和窗口自动折行，以设备输出的换行为边界，不跨行匹配。回车覆盖、退格或清行改变文字后会重新匹配。高亮只作用于串口画面的文字前景色，不改变背景、收发数据、复制出的文本和日志文件，也不影响本地终端或 SSH。

代码组织与验证

串口功能的文件分工

我把新增功能分别放在串口、日志和高亮模块中，配置、设备读写、文件保存、文字着色、菜单与状态显示各自维护。接入上游共用文件的位置使用 scnterm: 注释说明，方便查看改动和合并 WezTerm 更新。

位置 职责
config/src/serial.rs 串口连接参数定义、校验与转换
pty/src/serial.rs 系统串口打开、数据收发、连接结束与句柄释放
wezterm-gui-subcommands/src/serial.rs、wezterm-gui/src/serial.rs 命令行参数和串口窗口启动
mux/src/domain.rs 将串口连接接入终端窗格，按连接类型处理启动行为
config/src/serial_logging.rs 日志目录、大小和时间戳配置
mux/src/serial_log/ 文本处理、后台写入、分文件和相关测试
wezterm-gui/src/serial_logging.rs 日志菜单操作、顶部状态和错误提示
config/src/serial_highlighting.rs 高亮规则、颜色校验和正则编译
wezterm-gui/src/serial_highlighting.rs 匹配串口文字、按规则着色和缓存结果

串口读写不依赖日志模块。接收数据送往终端显示时，另外交给日志模块处理；日志开关和文本整理不改变实际收发的数据。高亮在界面绘制时处理，不依赖日志是否开启。后续 HEX 收发继续独立组织字节处理功能。

后续个性化开发计划
