Linux Ghostty 外观与窗格快捷键配置

发表于2026-11-05|更新于2026-11-05|软件

配置文件与仓库

Ghostty 使用每行一个 配置项 = 值 的文本配置。这里记录 Ghostty 1.4.0 在 Linux 上使用的外观、鼠标和窗格快捷键。

完整配置见 personal-config 的 Ghostty 目录，包含 config.ghostty、四款 Nerd Font 字体、字体授权、背景图片和安装脚本。各项设置说明见 Ghostty 官方配置参考。

文件或目录 用途
~/.config/ghostty/config.ghostty 终端配置
~/.config/ghostty/imgs/saber.jpg 使用仓库安装脚本后保存的背景图片
~/.local/share/fonts/JetBrainsMonoNerdFont/ 用户字体目录
~/.config/starship.toml Bash 中的路径色块与提示符
~/.bashrc Bash 加载 Starship 的初始化代码

~ 表示当前用户目录。设置了 XDG_CONFIG_HOME 时，Ghostty 配置位于该目录下的 ghostty/。

字体、配色与留白

截图展示使用主题背景色时的字体与 Starship 提示符。背景图片可按下一节单独启用。

字体使用 JetBrainsMono Nerd Font Mono，字号为 14，支持箭头和图标。背景完全不透明，左右留白为 12，上下留白为 10；输入时隐藏鼠标指针。

本机也可用字体别名 JetBrainsMono NFM，两种名称均匹配同一份常规字体文件。迁移到其他机器后，用 fc-match 检查实际匹配结果。

背景图片

手动配置时，把示例路径中的 your-user 替换为自己的用户名，或者直接填写背景图片的实际绝对路径。图片居中铺满窗口，图片不透明度设为 0.15。

background-opacity 控制窗口背景整体的不透明度，background-image-opacity 控制图片层的不透明度。删除 background-image 后使用主题背景色。

鼠标复制与粘贴

选中文本后复制到系统剪贴板，右键粘贴。鼠标事件传递保持开启，终端内支持鼠标的程序可以处理滚轮等操作。

分屏与窗口快捷键

窗格是标签页内的分屏区域。窗格放大只占满当前标签页，全屏与窗口最大化则作用于整个 Ghostty 窗口。

操作 快捷键
左右分屏 Ctrl + Shift + F1
上下分屏 Ctrl + Shift + F2
关闭当前窗格并确认 Ctrl + Shift + F3
放大或恢复当前窗格 Ctrl + Shift + F4
按方向切换输入焦点 Ctrl + Shift + 方向键
按方向调整窗格大小 Ctrl + Alt + Shift + 方向键
新建标签页 Ctrl + Shift + T
新建窗口 Ctrl + Shift + N
重载终端配置 Ctrl + Shift + R
进入或退出全屏 Alt + Enter
GNOME 窗口最大化或还原 Alt + F10

调整窗格大小

Ghostty 的调整单位是像素。仓库默认每次移动 10 像素，本机将四个方向均设为 40 像素：

使用仓库配置时，直接修改原有四条绑定末尾的数字。需要细调时减小数值，需要一次移动更大距离时增大数值。

Ghostty 1.4.0 提供切换焦点、调整大小和放大窗格的动作，没有交换窗格内容或整体轮换内容的动作。已有窗格的位置不会随 goto_split 改变。可在终端查看本机支持的动作：

动作含义见 Ghostty 快捷键动作说明。

路径箭头与 Bash 提示符

命令行中的时间、用户名、完整路径、Git 信息和色块箭头由 Starship 生成。Ghostty 负责显示字符，Nerd Font 提供箭头和图标。

这套提示符按“时间、用户名、完整路径、命令输入”排列。Git、开发工具版本和 Docker 信息显示在上方；没有相关信息时，上方信息行隐藏。安装、初始化和布局配置见 Starship 色块箭头提示符配置。

修改内容 文件
字体、字号、背景、窗格和鼠标 ~/.config/ghostty/config.ghostty
路径长度、色块和提示符内容 ~/.config/starship.toml
Bash 是否启用 Starship ~/.bashrc

修改终端配置后按 Ctrl + Shift + R。修改 Bash 初始化代码后新建标签页；仅重载 Ghostty 配置不会重新初始化已运行的 Bash。

迁移配置

迁移终端外观时，保留 Ghostty 配置、字体和背景图片，并检查图片绝对路径。迁移提示符时，还需保留 Starship 程序、starship.toml 和 .bashrc 中的初始化代码。

Windows 终端配置见 Windows WezTerm 外观与窗格快捷键配置。
