Ubuntu 26.04 安装 Fcitx5、Rime 与雾凇拼音

发表于2026-09-19|更新于2026-10-15|软件

环境与组件

本文适用于 Ubuntu 26.04 的 GNOME/Wayland 桌面。中文输入法与系统显示语言分开设置，安装过程中无需修改 LANG、LC_ALL，系统界面和地区格式可以保持原来的英文设置。

2026 年 10 月安装验证使用的环境如下：

组件 版本或配置
操作系统 Ubuntu 26.04.1 LTS
桌面 GNOME Shell 50.1
显示系统 Wayland
输入法框架 Fcitx5 5.1.19
Rime 插件 fcitx5-rime 5.1.13
Rime 引擎 librime 1.16.1，包含 Lua 插件
输入方案 雾凇拼音 rime_ice
GNOME 候选面板扩展 Kimpanel 92，支持 GNOME 50

各组件的作用：

  • Fcitx5：连接应用与输入法，管理输入法切换和候选窗口。
  • fcitx5-rime：让 Fcitx5 使用 Rime 输入引擎。
  • 雾凇拼音：提供 Rime 的拼音方案、词库和 Lua 功能，例如日期、数字转换等。
  • Kimpanel：由 GNOME 显示输入法候选面板，改善 Wayland 下候选框的位置。

本次安装前使用 IBus 与智能拼音。安装后已完成雾凇拼音词库编译；启用 Kimpanel 后，原先偏离输入位置的候选框已能跟随光标。

4. 添加 Rime 并选择雾凇拼音

打开配置工具：

在 Input Method（输入法） 页面操作：

  1. 保留原来的键盘布局，用于英文和直接按键输入。
  2. 取消 Only Show Current Language（仅显示当前语言），避免英文环境隐藏中文输入法。
  3. 在可用输入法列表中搜索 rime，选中 Rime／中州韵。
  4. 点击添加按钮；左右双列表界面中，该按钮是两栏之间指向左侧的箭头。
  5. 确认当前输入法列表包含键盘布局和 Rime，点击 Apply（应用）。

在 Global Options（全局选项） 中确认切换快捷键，通常可以使用 Ctrl+Space 激活或关闭中文输入。

在文本输入框中切换到 Rime，按 F4 或 Ctrl+反引号 打开方案菜单，选择 雾凇拼音。反引号键通常位于数字 1 左边。

配置工具中添加的是 Rime，雾凇拼音则在 Rime 的方案菜单中选择。修改方案文件或更新词库后，可以在 Fcitx5 的 Rime 菜单中执行 Deploy（部署），重新加载配置。

5. 安装 Kimpanel，修复候选框位置

GNOME/Wayland 下，Fcitx5 的候选框可能出现在远离输入光标的位置。原因与应用提供的光标坐标、Wayland 的窗口定位限制有关；修改雾凇拼音词库不会修复候选窗口的位置。Fcitx 官方文档推荐使用 GNOME 的 Kimpanel 扩展协助显示候选面板。GNOME/Wayland 配置说明

本环境在多个应用中出现候选框偏移，安装并启用 Kimpanel 后，已确认候选框可以跟随输入光标。

配置窗口为空或没有输入法进程

fcitx5 -d 仅启动当前会话，不会替代登录自启动配置。若仍无法使用，生成诊断报告：

Shift 没有按预期切换

Fcitx5 的框架切换与 Rime 内部的中英文切换是两套设置。先使用 Ctrl+Space 激活 Rime，再测试 Shift；雾凇拼音默认将左 Shift 用于切换中英文。需要自定义时，分别查看 Fcitx5 的全局快捷键和 Rime 的 ascii_composer 配置，避免给同一个按键设置重复动作。

只有某个应用不能输入或候选框偏移

先关闭并重新打开该应用，确认它已使用重新登录后的输入法环境。若其他应用正常，再针对该应用检查 Wayland/XWayland 运行方式和输入法支持。系统安装 GTK、Qt 输入组件不代表所有 Flatpak 应用都已包含相应组件，仍需核对具体应用的运行环境。
