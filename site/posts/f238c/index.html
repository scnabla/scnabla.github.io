Windows WezTerm 外观与窗格快捷键配置

发表于2026-11-01|更新于2026-11-05|软件

配置文件与仓库

Windows 使用 WezTerm 20260917-114457-b09b56c2，默认启动 PowerShell 7；未安装时回退到 Windows PowerShell。终端的字体、背景、鼠标和窗格快捷键由 wezterm.lua 管理。

完整配置见 personal-config 的 Windows WezTerm 目录。该目录独立包含配置、四款字体、字体授权和背景图片。安装 WezTerm 后，将 wezterm.lua、fonts/ 和 imgs/ 直接复制到 %USERPROFILE%\.config\wezterm\：

%USERPROFILE% 是 Windows 当前用户目录。覆盖前先备份已有配置。如果 wezterm.exe 所在目录还放有 wezterm.lua，先检查该文件：程序目录中的配置优先于上面的用户配置目录。自定义配置路径和完整查找顺序见 WezTerm 配置文件说明。

下面的 Lua 片段用于说明仓库配置中的具体设置，放在已有 config 对象上、return config 之前。修改列表时编辑原有 config.keys 和 config.mouse_bindings，避免用第二份列表覆盖其他绑定。

外观设置

截图记录了背景图片、标签栏与提示符的搭配。路径色块由 PowerShell 中的 Starship 生成，配置方法见后文。

字体、配色与分隔线

正文使用 JetBrainsMono Nerd Font Mono，字号为 12，字体文件位于配置旁的 fonts/ 目录。分屏分隔线设为橘黄色 #FFB000，背景完全不透明，窗口内边距沿用默认值。

背景图片

现有配置将图片相对路径保存在 compat.paths.background_image 中，并在图片存在时加载：

compat.paths.background_image 当前为 imgs/saber.jpg。enabled 和 compat 是这份配置文件定义的开关与辅助函数，保留在文件前部。图片亮度设为 0.15，降低背景图片对文字阅读的干扰，原图文件保持不变。迁移配置时一并复制 imgs 目录。

标签栏、光标与滚动条

标签栏位于顶部，只有一个标签页时也显示。Windows 标签栏使用 Microsoft YaHei UI，正文字体保持原设置。光标为闪烁竖线，闪烁间隔为 800 毫秒，窗口显示滚动条。

当前窗格和窗口提示

非当前窗格降低亮度与饱和度：

现有文件还通过 format-tab-title、window-focus-changed 和 format-window-title 等回调设置提示：

  • 当前标签名称前显示“当前”和标签序号。
  • 获得键盘焦点的窗口，其当前标签使用蓝色背景 #89b4fa；其他窗口的当前标签使用灰色背景 #45475a。
  • 标签栏左侧显示“当前窗口”或“未激活”。
  • 窗口标题显示当前标签序号与标签总数；窗格放大时追加 [窗格已放大]。

这组设置由文件前部的 enabled.focus_indicator 开关控制，当前为 true。

鼠标复制与粘贴

左键选择后松开即复制，右键粘贴；按住 Ctrl 点击链接时打开链接。

分屏与窗口快捷键

窗格是同一个标签页里的分屏区域；窗口是 Windows 管理的独立窗口。放大窗格、最大化窗口和全屏是三种不同操作。

操作 快捷键
左右分屏 Ctrl + Shift + F1
上下分屏 Ctrl + Shift + F2
关闭当前窗格并确认 Ctrl + Shift + F3
放大或恢复当前窗格 Ctrl + Shift + F4
正向轮换所有窗格内容 Ctrl + Shift + F5
按方向切换输入焦点 Ctrl + Shift + 方向键
按方向调整窗格大小 Ctrl + Alt + Shift + 方向键
新建标签页 Ctrl + Shift + T
新建窗口 Ctrl + Shift + N
重载配置 Ctrl + Shift + R
打开中文命令面板 Ctrl + Shift + P
打开启动菜单 Alt + L
进入或退出全屏 Alt + Enter
窗口最大化 Win + ↑
从最大化恢复窗口 Win + ↓

调整窗格大小

左右方向每次调整四列，上下方向每次调整两行。这里的列和行是终端字符单元，实际像素距离随字体、字号和缩放比例变化。

以上两行对应 config.keys 中的条目。需要改变步进时，同步修改左右两个方向和上下两个方向。

正向轮换内容

按 Ctrl + Shift + F5 直接轮换所有窗格内容，无需选择字母。屏幕上的窗格大小与布局不变，输入焦点留在原位置。

例如焦点在最左侧，三个横排窗格连续轮换：

轮换作用于整个标签页，其他窗格内容也一起移动。复杂分屏按照程序内部的窗格顺序轮换，不按鼠标指向选择目标。动作定义见 RotatePanes 官方说明。

关闭确认

关闭窗口时要求确认；关闭当前窗格的 F3 绑定也显式使用 confirm = true。

SSH 启动菜单

将文件前部 enabled 表中的 ssh 改为 true，然后按 Alt + L 选择 SSH 入口。密码不写入配置文件。

该配置使用 multiplexing = 'None'，通过普通 SSH 连接，服务器不需要安装 WezTerm。地址变化后，旧进程的启动菜单可能继续显示旧条目；保存工作、关闭所有 WezTerm 窗口后重新打开，再核对入口地址。相关重载问题见 WezTerm #7072。

路径箭头与 PowerShell 提示符

WezTerm 控制字体和显示窗口；命令行里的时间、用户名、路径色块和箭头由 Starship 提示符生成。

内容 配置位置
字体、背景、分屏与鼠标 %USERPROFILE%\.config\wezterm\wezterm.lua
路径、色块与 Git 信息 %USERPROFILE%\.config\starship.toml

修改内容 配置项或文件
