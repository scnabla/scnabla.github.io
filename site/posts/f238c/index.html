Windows WezTerm 个人配置

发表于2026-11-01|更新于2026-11-05|软件

Windows 日常终端使用 WezTerm，默认打开 PowerShell 7，通过启动菜单连接 SSH。正文使用 JetBrainsMono Nerd Font Mono，配色为 Catppuccin Mocha，背景配合 Saber 图片；多窗格使用明暗区分，常用操作集中在 Ctrl + Shift 组合键。

完整配置保存在 personal-config/terminal/wezterm/windows。该目录独立维护 wezterm.lua、字体和背景图片。

配置文件

内容 位置
终端配置 %USERPROFILE%\.config\wezterm\wezterm.lua
正文字体 配置目录内的 fonts/
背景图片 配置目录内的 imgs/saber.jpg
Starship 提示符 %USERPROFILE%\.config\starship.toml
PowerShell 初始化 PowerShell 7 的 $PROFILE

%USERPROFILE% 是 Windows 当前用户目录。配置、字体和图片放在一起，换电脑时复制仓库 windows/ 目录中的 wezterm.lua、fonts/ 和 imgs/ 到对应位置即可。字体由 WezTerm 直接读取，包含常规、粗体、斜体和粗斜体四款，授权文件为 fonts/OFL.txt。

wezterm.lua 前部集中保存功能开关、程序名、路径、SSH 信息和标签栏字体，后面按启动、外观、鼠标、按键、命令面板等分段。源码见 wezterm.lua。

启动与 SSH

默认 Shell 优先使用 PowerShell 7，找不到时使用 Windows PowerShell，再回退到命令提示符。启动目录使用当前用户目录，由 compat.paths.windows_project 设置。

Alt + L 打开启动菜单，包含本机默认 Shell，以及启用后出现的 SSH 入口。本地使用的服务器信息保存在 compat.ssh，公开配置中的地址和用户名为示例：

公开配置的 enabled.ssh 为 false；本地填写连接信息后设为 true。连接使用普通 SSH，multiplexing = 'None'，远端不需要安装 WezTerm，也不会在启动窗口时自动连接。密码不写入配置。

修改 SSH 地址后，旧进程的启动菜单可能保留原条目，需要关闭所有 WezTerm 窗口后重新打开。该行为有对应的 WezTerm 重载问题记录。

字体与背景

项目 当前设置
正文字体 JetBrainsMono Nerd Font Mono
字号 12
默认配色 Catppuccin Mocha
背景不透明度 1.0
背景图片 imgs/saber.jpg
图片亮度 0.15
分屏分隔线 橘黄色 #FFB000
窗口内边距 WezTerm 默认值

字体目录通过 wezterm.config_dir .. '/fonts' 定位，背景图片也从配置目录读取。图片文件不存在时使用配色背景，字体、配色和快捷键仍继续加载。

默认配色保存在 config.color_scheme，图片亮度保存在 config.window_background_image_hsb。窗口背景保持不透明，通过降低图片亮度让文字更清楚。

标签栏与当前输入位置

标签栏放在顶部，只有一个标签页时也显示。标签栏使用 Microsoft YaHei UI，正文继续使用 Nerd Font。

多个窗格同时打开时，当前窗格保持正常亮度；其他窗格的饱和度为 0.8、亮度为 0.35。输入位置还通过标签和窗口提示区分：

  • 当前标签名称前显示“当前”和标签序号。
  • 正在接收键盘输入的窗口，其当前标签为蓝色；其他窗口的当前标签为灰色。
  • 标签栏左侧显示“当前窗口”或“未激活”。
  • 窗口标题显示当前标签序号和标签总数，放大窗格时追加 [窗格已放大]。

这些设置统一由 enabled.focus_indicator 控制。默认保留自定义标签名，没有自定义名称时显示当前窗格标题。

鼠标、光标与滚动

操作或项目 当前行为
左键选择文本后松开 复制到系统剪贴板
右键点击 粘贴系统剪贴板
Ctrl + 左键 点击链接 打开链接
输入光标 闪烁竖线，间隔 800 毫秒
滚动条 显示
历史输出行数 WezTerm 默认值
终端响铃 关闭

鼠标操作集中在 config.mouse_bindings，普通左键用于选择，打开链接需要按住 Ctrl。

窗格与窗口操作

操作 快捷键
左右分屏 Ctrl + Shift + F1
上下分屏 Ctrl + Shift + F2
关闭当前窗格并确认 Ctrl + Shift + F3
放大或恢复当前窗格 Ctrl + Shift + F4
正向轮换窗格内容 Ctrl + Shift + F5
向相邻窗格切换输入焦点 Ctrl + Shift + 方向键
调整窗格大小 Ctrl + Alt + Shift + 方向键
新建标签页 Ctrl + Shift + T
切换到上一个、下一个标签页 Ctrl + Shift + Tab、Ctrl + Tab
新建窗口 Ctrl + Shift + N
全屏或退出全屏 Alt + Enter

窗格大小按字符单元调整：左右每次四列，上下每次两行。字体或字号改变后，一次调整对应的像素距离也会变化。

Ctrl + Shift + F5 每按一次，所有窗格内容正向轮换一次，焦点留在原来的屏幕位置。以三个横排窗格、焦点在左侧为例：

轮换保留原有布局和每个位置的大小。实现使用 RotatePanes 'Clockwise'，按照标签页内部的窗格顺序轮换，说明见 WezTerm RotatePanes。

F4 放大的是标签页内的一个窗格，Alt + Enter 切换的是整个窗口的全屏状态。Windows 的窗口最大化、还原分别使用系统快捷键 Win + ↑、Win + ↓。

中文命令面板

Ctrl + Shift + P 打开命令面板。配置增加了中文入口，并在名称旁显示对应快捷键；没有绑定的操作标记为“未绑定快捷键”，可以直接从面板执行。

面板涵盖配置重载、新建和关闭终端、复制粘贴、搜索、字号调整、滚动、窗口置顶、标签页切换、窗格操作和调试信息。内置英文命令同时保留。

窗格相关菜单还包含选择窗格、交换两个窗格的位置，以及将窗格移到新标签页或新窗口。日常正向轮换直接使用 Ctrl + Shift + F5。

关闭确认与渲染

窗口关闭设置为 AlwaysPrompt，关闭当前窗格的快捷键也要求确认。skip_close_confirmation_for_processes_named 设为空列表，不因窗格中仅运行 PowerShell 等程序而跳过确认。

渲染使用 OpenGL，帧率和显卡选择沿用默认设置。渲染方式修改后需要完整退出并重新启动 WezTerm。

功能开关

开关 公开配置默认值 控制内容
windows_settings true Shell、启动目录和 Windows 标签栏字体
ssh false SSH 启动菜单入口
background true 背景图片与图片亮度
chinese_commands true 中文命令面板入口
focus_indicator true 窗格明暗、当前标签与窗口提示

修改终端设置后按 Ctrl + Shift + R 重载。Shell 和启动目录设置影响之后新建的会话。若同时存在程序目录和用户目录两份 wezterm.lua，程序目录中的文件优先加载，查找规则见 WezTerm 配置说明。

路径色块与箭头

PowerShell 使用 Starship 提示符。时间、用户名、完整路径和箭头排在主提示符中，Git、开发工具版本等附加信息显示在上方。WezTerm 配置只负责字体和显示，提示符内容由 starship.toml 管理。

Starship 通过 PowerShell 7 的 $PROFILE 初始化。修改初始化代码后，新建标签页，或在现有 PowerShell 会话执行 . $PROFILE。安装和提示符内容见 Starship 色块箭头提示符配置。

通过 SSH 连接 Linux 后，路径箭头来自远端 Shell 的提示符配置，与 Windows 本机的 starship.toml 分开维护。

Linux 端使用的终端配置见 Linux Ghostty 个人配置。
