Windows WezTerm 与 Linux Ghostty 的个人终端美化配置

发表于2026-11-01|更新于2026-11-01|软件

终端与配置文件

Windows 使用 WezTerm，Linux 使用 Ghostty。两端保留各自的配色与外观，常用分屏、窗格切换和全屏快捷键保持一致。

以下配置记录于 2026 年 11 月 1 日。

项目 Windows Linux
终端 WezTerm 20260917-114457-b09b56c2 Ghostty 1.3.0-dev+0000000
配置文件 %USERPROFILE%\.config\wezterm\wezterm.lua ~/.config/ghostty/config.ghostty
配色 Catppuccin Mocha Monokai Classic
正文字体 JetBrainsMono Nerd Font Mono JetBrainsMono Nerd Font Mono
字号 12 14
背景不透明度 1.0 1
背景图片 imgs/saber.jpg，亮度 0.2 主题背景色

%USERPROFILE% 是 Windows 当前用户目录，~ 是 Linux 当前用户目录。WezTerm 使用 Lua 配置；Ghostty 使用每行一个 配置项 = 值 的文本配置。

Linux Ghostty 外观

在 ~/.config/ghostty/config.ghostty 中设置：

字体使用 JetBrainsMono Nerd Font Mono，支持色块箭头和图标，字号为 14。背景完全不透明，左右留白为 12，上下留白为 10；输入时隐藏鼠标指针。

Bash 色块箭头提示符

Linux 的 Bash 已启用 Starship 1.27.0。主提示符按“时间 → 用户名 → 完整路径 → 命令输入”排列，保留 Pastel Powerline 色块与中间箭头分隔，时间色块左侧使用平直边缘，路径色块右侧以箭头收尾；用户主目录用 ~ 表示，时间显示为 HH:MM，不带心形符号。Git 分支及状态、开发环境版本和 Docker 上下文合并在主提示符上方的一行，分别使用橙色、浅蓝色和青色背景，文字为深色。开发工具显示具体名称和版本，包含 Node.js、Python、Go、Rust 等，例如 Node.js v24.21.0，不显示笼统的“环境”标签。各色块内容左右各留一个空格，宽度随内容变化，整组提示符左对齐。没有内容的项目连同色块一起隐藏，全部为空时隐藏整行。整组前留一个空行，与上一条命令的输出分开。普通目录显示一行内容，有附加信息时显示两行，另计前面的空行和窗口宽度导致的自动换行。

配置分布在三个文件中：

  • ~/.bashrc：在末尾初始化 Starship。
  • ~/.config/starship.toml：配置色块、模块和目录显示方式。
  • ~/.config/ghostty/config.ghostty：选择 JetBrainsMono Nerd Font Mono 字体。

安装、字体设置、生效方法与恢复步骤见Ghostty 与 WezTerm 配置 Starship 色块箭头提示符。Windows PowerShell 7 同样启用这套提示符配置，工具版本按各端实际环境显示。

下方 Lua 代码是现有文件中的功能片段，修改时放在已有 config 对象上、return config 之前。同一配置项直接修改原值，config.keys 和 config.mouse_bindings 在原有列表中维护。

字体、配色与分隔线

正文使用 JetBrainsMono Nerd Font Mono，字号为 12，字体文件位于配置旁的 fonts/ 目录。分屏分隔线设为橘黄色 #FFB000，背景完全不透明，窗口内边距沿用默认值。

PowerShell 提示符

Windows 默认 Shell 为 PowerShell 7，使用 Starship 1.27.0。提示符配置位于 %USERPROFILE%\.config\starship.toml，与 Linux 使用相同布局。程序放在 %LOCALAPPDATA%\Programs\Starship\，由 PowerShell 7 的 $PROFILE 初始化。

重载 WezTerm 字体后新建标签页即可使用；已有 PowerShell 7 会话执行 . $PROFILE。安装与初始化代码见Starship 色块箭头提示符配置。

背景图片

现有配置将图片相对路径保存在 compat.paths.background_image 中，并在图片存在时加载：

compat.paths.background_image 当前为 imgs/saber.jpg。enabled 和 compat 是这份配置文件定义的开关与辅助函数，保留在文件前部。图片亮度设为 0.2，降低背景图片对文字阅读的干扰，原图文件保持不变。迁移配置时一并复制 imgs 目录。

标签栏、光标与滚动条

标签栏位于顶部，只有一个标签页时也显示。Windows 标签栏使用 Microsoft YaHei UI，正文字体保持原设置。光标为闪烁竖线，闪烁间隔为 800 毫秒，窗口显示滚动条。

当前窗格和窗口提示

非当前窗格降低亮度与饱和度：

现有文件还通过 format-tab-title、window-focus-changed 和 format-window-title 等回调设置提示：

  • 当前标签名称前显示“当前”和标签序号。
  • 获得键盘焦点的窗口，其当前标签使用蓝色背景 #89b4fa；其他窗口的当前标签使用灰色背景 #45475a。
  • 标签栏左侧显示“当前窗口”或“未激活”。
  • 窗口标题显示当前标签序号与标签总数；窗格放大时追加 [窗格已放大]。

这组设置由文件前部的 enabled.focus_indicator 开关控制，当前为 true。

配色切换和预览

现有配置增加了中文命令入口。按 Ctrl+Shift+P 打开命令面板，搜索以下名称：

命令 行为
外观：切换配色 打开内置配色列表，按名称搜索并应用到当前窗口
外观：实时预览配色 用左右方向键依次预览，右侧状态栏显示配色名称
外观：保存当前配色为默认 将当前内置配色写入配置文件的 config.color_scheme

实时预览期间，Enter 保留当前窗口的配色并退出预览，Esc 恢复进入预览前的配色。要让以后新开的窗口使用所选配色，执行“外观：保存当前配色为默认”。这些入口来自个人配置中的回调代码，迁移时需要保留对应代码。

Linux 的 Codex CLI 另在 ~/.codex/config.toml 中启用选中复制：

已有 [tui] 段时，在该段内修改这个字段。

WezTerm

左键选择后松开即复制，右键粘贴；按住 Ctrl 点击链接时打开链接。

两端统一的快捷键

窗格是同一个标签页内的分屏区域；窗口是操作系统管理的独立终端窗口。窗格放大、窗口最大化和全屏分别使用不同快捷键。

操作 快捷键
左右分屏 Ctrl+Shift+F1
上下分屏 Ctrl+Shift+F2
关闭当前窗格并确认 Ctrl+Shift+F3
放大或恢复当前窗格 Ctrl+Shift+F4
按方向切换窗格 Ctrl+Shift+方向键
新建标签页 Ctrl+Shift+T
上一个、下一个标签页 Ctrl+PageUp、Ctrl+PageDown
新建窗口 Ctrl+Shift+N
重载终端配置 Ctrl+Shift+R
进入或退出全屏 Alt+Enter
窗口最大化 Win/Super+↑
从最大化恢复窗口 Win/Super+↓

Super 对应常见 PC 键盘上的 Windows 徽标键。最大化与还原由系统桌面处理；Linux 当前由 GNOME 的 Tiling Assistant 扩展提供这组上下方向键绑定。还原操作用于已最大化的窗口。

Ghostty 自定义按键

标签页和新建窗口使用默认绑定。Linux 同时保留 GNOME 的 Alt+F10 最大化切换快捷键。

WezTerm 自定义按键

重载配置、方向切换窗格、新建标签页和新建窗口使用 WezTerm 默认绑定。Alt+L 打开启动菜单，可选择配置中的本地 Shell 或 SSH 入口。

日常修改位置

修改内容 文件与配置项
Linux 字号、配色、留白 config.ghostty 中的 font-size、theme、window-padding-x/y
Linux 色块箭头提示符 ~/.config/starship.toml，由 ~/.bashrc 初始化
Windows 字号和默认配色 wezterm.lua 中的 config.font_size、config.color_scheme
Windows 背景图片 compat.paths.background_image 与 imgs/ 目录
Windows 背景亮度 config.window_background_image_hsb
Windows 分隔线颜色 config.colors.split
Windows 非当前窗格明暗 config.inactive_pane_hsb
窗格与全屏快捷键 Ghostty 的 keybind，WezTerm 的 config.keys

修改终端配置后按 Ctrl+Shift+R 重载。修改 Bash 初始化设置后执行 source ~/.bashrc。迁移个人设置时，保留 Ghostty 配置、Starship 程序与配置、Bash 中的初始化设置、Nerd Font 字体，以及 WezTerm 的完整 wezterm.lua 和背景图片目录。
