Ghostty 与 WezTerm 配置 Starship 色块箭头提示符

发表于2026-11-01|更新于2026-11-01|软件

当前配置

命令行中的色块和箭头由 Starship 提示符生成。Bash 在显示命令输入位置时调用 Starship，Ghostty 使用 Nerd Font 字体显示箭头与图标。

2026 年 11 月 1 日的个人配置如下：

项目 配置
终端 Ghostty
Shell Bash
提示符程序 Starship 1.27.0
提示符预设 Pastel Powerline
字体 JetBrainsMono Nerd Font Mono
字号 14
终端配色 Monokai Classic

当前在 Pastel Powerline 基础上将附加信息合并到一行，显示在主提示符上方。主提示符按时间、用户名、完整路径排列，路径后直接输入命令。Git、开发环境和 Docker 均无信息时，上方信息行隐藏。时间位于主提示符最左端，显示为 HH:MM，不带心形符号。Git 和开发工具信息按当前目录显示。预设要求安装并启用 Nerd Font，参见 Starship 官方预设说明。

文件位置

文件或目录 用途
~/.local/bin/starship Starship 可执行文件
~/.config/starship.toml 提示符预设与个性化设置
~/.bashrc Bash 启动时加载 Starship
~/.config/ghostty/config.ghostty Ghostty 字体和外观
~/.local/share/fonts/JetBrainsMonoNerdFont/ 用户字体目录
~/.local/state/terminal-style-backups/20261101-003954/ 启用前的 Bash 和 Ghostty 配置备份

外层括号将附加信息和换行放在同一组，内部三个括号组分别控制 Git、开发环境和 Docker 的名称与内容。整组无内容时不产生信息行。时间、用户名和完整路径始终保持在同一条主提示符中。add_newline = true 在整组提示符前增加一个空行，与上一条命令的输出分开。条件分组语法见 Starship 配置说明。

在原有模块设置中，将信息行的 style 设置为深色文字和对应背景色：

模块 style
git_branch、git_status "fg:#1e1e2e bg:#FCA17D"
c、elixir、elm、golang、gradle、haskell、java、julia、maven、nodejs、python、bun、nim、rust、scala "fg:#1e1e2e bg:#86BBD8"
docker_context "fg:#1e1e2e bg:#06969A"

fg: 指定文字颜色，bg: 指定背景颜色。Git 使用橙色背景，开发环境使用浅蓝色背景，Docker 使用青色背景；类别名称与内容采用相同背景，空项目连同色块一起隐藏。主提示符的时间、用户名和路径继续使用色块，时间色块左侧使用平直边缘，路径色块右侧以箭头收尾，后留一个空格直接输入命令，中间保留箭头分隔。

日常调整与恢复

调整色块、显示内容和路径长度时编辑 ~/.config/starship.toml；调整字体、字号和终端背景时编辑 Ghostty 配置。

恢复普通 Bash 提示符时，删除 ~/.bashrc 末尾的 Starship 初始化代码块，然后新建一个标签页。恢复原来的内置字体时，删除 Ghostty 中的 font-family 这一行，再按 Ctrl+Shift+R 重载。

启用前的两个配置文件保存在 ~/.local/state/terminal-style-backups/20261101-003954/。整体恢复备份会同时覆盖备份之后对同一文件做出的修改。
